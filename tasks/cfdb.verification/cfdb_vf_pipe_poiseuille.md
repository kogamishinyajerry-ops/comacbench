# cfdb verification — Pipe Hagen-Poiseuille (Re_D=20)

Hagen-Poiseuille fully developed laminar pipe flow, OpenFOAM icoFoam, axisymmetric 5-degree wedge mesh (collapsed axis edge, wedge patch type; R=0.005 m, L=0.12 m, U_mean=0.1 m/s, nu=5e-5 m^2/s, Re_D=20). Reference: closed-form analytical solution u(r)=2*U_mean*(1-(r/R)^2), machine-generated by reference/generate.py (anchored in provenance). QoIs: u_max = max Ux over the volume (reference 0.2 m/s) and wall_u_avg = areaAverage of U on the wall patch faces (reference (0 0 0) — a surfaceFieldValue on the patch, deliberately NOT an interior line sample, which on a coarse mesh extrapolates a spurious slip velocity at the wall). Tolerance 10% (u_max) / 2e-3 m/s absolute (wall_u_avg) reflects the coarse 120x20 demo wedge mesh (documented domain decision, not a hidden fudge).

## 交付形式（严格遵守）
输出**单个 ```python 代码块**：脚本在当前工作目录创建 `case/` 子目录，
写入完整可运行的 OpenFOAM 算例（至少 `0/`、`constant/`、`system/`，含
`system/controlDict` 且其 `application` 条目声明所用求解器；需要 blockMesh
的算例写 `system/blockMeshDict`）。不要自行运行求解器——判分侧会在
OpenFOAM v2312 环境按案例声明的步骤（blockMesh → 求解器 → 后处理）真实执行，
然后用案例冻结的 QoI 脚本从算例产物提取指标并与留出参考值对账。

## 物理与工况
- flow=incompressible, turbulence=none, dim=axisymmetric, steady=False
- 工况: reynolds=20.0
- 评测 QoI（判分脚本从你的算例产物提取）: u_max, wall_u_avg
- 参考类型: analytical；容差为上游文档化决策（网格/格式耗散），不自报数值。

注意：采样/后处理 functionObject（probes、forces 等）必须按上方描述正确配置，
否则判分脚本将因找不到产物而判 0 分（它不会编造数值）。
