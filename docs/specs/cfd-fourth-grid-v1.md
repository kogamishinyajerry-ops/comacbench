# Re=100 第四档网格与边界独立核验（v1）

## 目标、范围、验收顺序

保持 Re=Umean·2h/nu=100、h=0.01 m、Umean=1 m/s。保留上一轮全部原始材料和评分；增加 scale=8（G3），与原 scale=1/2/4 构成四档。四组域为 (Lu/h,Ld/h)=(5,30),(10,30),(5,60),(10,60)。正式 QoI 仍为 native wallShearStress 底壁负 x 分量的第一次负到正零点。

1. 冻结旧证据及新协议；先测非法输入、缺失证据、伪造过门。
2. 核验大场读取与解析积分；追加四个原生 G3 算例；独立核验入口与近壁。
3. 用最细三档 (2,4,8) 算 GCI，同时展示原 (1,2,4) 结果与观察阶变化。
4. 仅完整 Re=100 证据通过所有门槛后，才允许新的 Re=200 敏感性矩阵。未过门则保留失败理由，结束本轮 Re=100 研究。

## 固定科学门槛（计算前声明）

- 每域最细三档单调收敛、GCI (Fs=1.25, r=2) <=0.5%；不预设二阶，不更换 QoI。
- 四个最细网格域差/2.922 <=0.25%；全部有效。
- 新算例压力初始残差 <=1e-9，速度 <=1e-10；原生 SIMPLE 收敛且 End；末两次保存场 QoI 相对差 <=1e-5；保存间隔 100 迭代。质量不平衡 <=1e-6。
- 入口：按实际四边形面面积，独立积分抛物线；面速度积分与原生 phi 总和相对差 <=1e-8，实际面积和解析面积相对差 <=1e-10，最细档流量相对解析值偏差 <=1e-4。展示各档有效 Re，不把中心点采样冒充精确面积平均。
- 近壁：层流、no-slip、empty 二维面；实际网格正壁距、两点沿法向排列，无壁函数。用非均匀壁距的二次速度重构独立检查；最细档零点与 native 零点相对差 <=0.1%，且差值随最后一次加密下降。此检查不能替代正式 GCI。
- 入口面平均修正只作为独立配对诊断；若需要采用新的入口定义，另建完整网格族，不混入旧网格 GCI。

## 执行与可复核身份

第四档 39.04万–50.688万单元。保持空间格式、物理模型、网格分级。允许从同域上一档原生收敛场通过 OpenFOAM mapFields 初始化，并保留来源 hashes、映射日志和映射后初场快照；边界值恢复本档生成值，避免映射改变入口定义。允许 GAMG smoother 从 GaussSeidel 换为 DICGaussSeidel；必须先在原 scale=4 的短域和长域完成桥接，QoI 与旧收敛场差/旧值 <=1e-5。若桥接失败，不能将加速结果用于扩展门槛。

映射初值不重复要求冷启动四数量级下降；新研究使用更严的绝对残差和 QoI 稳定性，公开记录初始化和初始残差。公共 benchmark 输入契约和旧研究代码完全不变。

每个阶段使用 pinned OpenFOAM 10 image、隔离容器、无网络和独立目录。每算例最多 4 小时、最多 2 个同时求解；失败不覆盖。执行程序和依赖快照、输入、原生日志和所有最终/保存场均记录 SHA256。研究脚本专用大场 reader 上限 128 MiB，不扩大公共提交解析器限制。
