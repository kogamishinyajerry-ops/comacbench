# CFD 网格与域长度研究方案

目标：用真实 OpenFOAM 10 数据校核后向台阶 Re=100 的 10% 参考容差，完成判断后再扩展一个相邻层流工况。单 agent 执行；原评测包、检查器与历史结果冻结不改。

## 预先声明的实验

- 三档在平面内加密 r=2 的网格：G0、G1、G2，基础短域约 6100 / 24400 / 97600 单元；二维厚度方向仍为一层。
- 四种域：入口/出口长度为 (5h,30h)、(10h,30h)、(5h,60h)、(10h,60h)，共 12 个 Re=100 算例。分别报告入口与出口效应及交互，不把总单元数变化当成局部加密。
- 所有域保持下游 0..30h 的分段网格形状和台阶近区尺寸一致；新增出口段使用独立 uniform segment，延长入口按原 dx 加单元。固定几何、Um、nu、离散格式、求解器镜像及 QoI 定义。
- 研究收敛比原包更严格：SIMPLE p≤1e-8、U≤1e-9；p/U 线性求解容差分别 1e-10/1e-11。最大 30000 次、每次运行最多 1800 秒；每 500 次及最后写场，不删除失败档案。末两保存场 QoI 相对变化须≤1e-4，边界通量相对不平衡≤1e-6。
- 原生 blockMesh/checkMesh 后，核对实际几何、单元数、面坐标、入口剖面与近台阶网格一致性。直接从 wallShearStress 重算首个再附着点，保留 U/p/phi、mesh、日志、全输入及摘要。

## 分析与判定

对每种域分别计算三网格差值、观察阶数、Richardson 外推和 GCI（安全系数 1.25）。无效、非单调或无正观察阶时，报告不适用，不硬填阶数或收敛结论。三点拟合得到的接近 1 的渐近比只作一致性描述，不能独立证明已达渐近区。

预先选用的研究门：12 次运行均有效；每域 fine-grid GCI≤0.5%；细网格域效应≤0.25%；末两场变化≤0.01%。满足后才能进行相邻 Re=200（原文表 5：X1/h=4.982）的三网格与至少一项域对照。若不满足，追加诊断/加密，不改变门槛迎合结果。

校核带：采用观测到的最差网格对文献偏差，加最大 fine-grid GCI（转换为文献参考相对量）、细网格域差、末两场变化和文献三位小数的半末位舍入量，向上取整到 0.5 个百分点。该求和是本研究的保守工程筛选规则，不是独立随机误差置信区间。比较 10% 是否明显大于此带；原包历史评分不回写，新阈值需单独版本和故障校准才能发布。

## 验收

- `python -m unittest tests.test_cfd_sensitivity -v` 对振荡/发散/非有限/缺网格输入先拒绝，并用已知二阶数列验证 GCI。
- `python studies/cfd_step_sensitivity.py run --out report/2026-09-06-cfd-sensitivity/re100` 生成 12 份独立原生结果；失败时保留原因，不宣称门通过。
- `analyze` 产出 JSON 与明确 tolerance_decision；`studies/render_cfd_sensitivity.py` 另行生成 CSV、科学图表与离线 HTML。新 Re 的运行必须引用已通过的 Re=100 决策摘要。
- `verify` 重算 QoI、核对身份与所有原生文件摘要；既有文件摘要不变。

## 独立诊断与运行时限补充

不改变上述数值门槛。壁面导数诊断在相同的已收敛 U 场上，使用真实两层单元中心与无滑移壁面拟合二次曲线；单独记录速度导数与原生应力张量的差别，不能替换正式 QoI 或用于绕过 GCI 门。入口面中心抛物线的离散通量偏差须明确报告，不能把连续平均速度与离散积分完全等同。

若原生运行达到 1800 秒时限，先保留失败结果及全部摘要；仅在存在完整 U/p/phi/wallShearStress 检查点时，用 `studies/cfd_study_continuation.py continue` 在新目录、新身份下额外运行最多 1800 秒。只把 `startFrom startTime` 改为 `latestTime`，不改网格、物理参数、离散格式、线性算法或收敛阈值。原始与续跑日志分开保留；连续残差历史是明确标注的派生文件，只衔接到实际保存检查点，不能拼入丢失迭代。

`resolve` 仅在全部算例有效后建立引用原始结果的汇总目录；首次超时仍显示为失败，续跑独立标明。完整复核须检查源失败、检查点字段摘要、运行设置、两份原生日志及合成关系。DICGaussSeidel 的短时成本诊断不纳入正式矩阵。
