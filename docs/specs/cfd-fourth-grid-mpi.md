# 不改变数值设置的 MPI 执行补充

采用原 p=0.3、U=0.7、DICGaussSeidel、相同空间离散和全部 v1 科学门槛。只将原生求解分成 4 个 MPI 分区（simple, 4×1×1），最后重构两个完整保存场；分区原始场和重构日志同时保留。每算例 4 CPU / 4 GiB / 256 PID，最多同时求解两个算例、每次最多 4 小时。

采用前已完成：短/长域同一初场的完整 MPI 桥接，QoI 相对原算例差分别 1.44921e-7、2.11856e-7，均小于 1e-5；两组网格散列完全一致。第四档真实 100 步计时，串行 46 秒、MPI 24 秒（求解阶段时钟，含求解器启动，不含分区），每步速度约提高 1.92 倍。该计时样本不算科学结果。

原串行尝试封存为 serial-attempts；从完整检查点复制场，保留重新开始前的独立快照，原数值设置不变。初次映射及串行续算原始日志分别保存。MPI 初始化可能改变收敛路径，所以最终仍必须重新通过全部原生质量门槛。
