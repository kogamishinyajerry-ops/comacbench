# Re=300 四网格 × 四域验证协议 v1

## Objective

在 Re=200 主回流区 v2 全矩阵证据重新通过后，真实运行 Re=300 的 16 个原生 OpenFOAM 算例，独立复核主涡身份、残差、守恒、入口、近壁、网格/域敏感性，重新形成研究筛查容差决策。

## Scope

- 二维稳态层流后向台阶，扩张比 2，h=0.01 m，Umean=1 m/s，Re=Umean·2h/nu，nu=0.02/300 m²/s。
- 四档 scale=1/2/4/8（G0–G3）；四域 (Lu/h,Ld/h)=(5,30),(10,30),(5,60),(10,60)。与前阶段的原生网格、入口面中心采样及离散格式一致。
- [Erturk 2008 DOI](https://doi.org/10.1016/j.compfluid.2007.09.003) Table 5：Re=300 的 X1/h=6.751；参考值不进入主涡/零点选择函数。仍用已冻结 `cfd_primary_recirculation.py` 的流函数连通与三条闭合等值线识别，并由 U/phi 两条路径、最后两次场核对归属。

## Constraints

1. 旧报告、旧源文件、公开评分和 10% 容差不修改。仅新增 Re=300 源码、测试、协议和报告；不调用模型，不自动扩展 Re=400。
2. 前置复核分别执行旧 Re=200 verify（复现原失败但校验原生和父阶段来源）、Re=200 主涡 v2 独立交付 verify（必须科学门槛通过），核验旧两份 delivery manifest、全部依赖和原生输入；两项只读复核均完成后才放行，日志与 SHA256 绑定到新身份。
3. 先用同域同网格 Re=200 场初始化 G0–G2，恢复目标边界。全部 12 组有效后，从同域 Re=300 G2 初始化 G3。G3 采用已有桥接证据支持的 4 分区 MPI。每个来源均校验版本、配置、结果与原生证据；不能仅信任 passed 标志。
4. 原求解设置保持：p=0.3/U=0.7、DICGaussSeidel、原空间格式、绝对残差 p≤1e-9、U≤1e-10、最多 60000 SIMPLE 步。每 100 步写场，ASCII 精度 12。
5. 因当前可用空间约 16 GiB，新算例使用 OpenFOAM 原生 `purgeWrite 2` 循环保存，只保留本次求解最近两次完整场、独立冻结的初值和全部求解日志。旧算例不清理。依据：[OpenFOAM v10 I/O control](https://doc.cfd.direct/openfoam/user-guide-v10/controldict)。首先在 Re=300、G0、5h/30h 做 purgeWrite 0/2 配对，来源相同；最后两次 U/p/phi/wallShearStress 必须一致，才放行其余矩阵。这是 I/O 证据保留变更，不更改物理方程或门槛。
6. 同时最多 2 个算例；串行 2 CPU/4 GiB，MPI 4 CPU/4 GiB；网络关闭，既有固定 OpenFOAM10 镜像。每次原生尝试最多 4 小时。开始一个算例需至少 6 GiB 空间，执行中低于 4 GiB 即停止本任务容器并保留产物。不得停止无关容器。
7. 逐例核验真实网格、完整原生日志和字段 hash；末两次 MPI 重构 U/p/下壁剪切沿用原验证器，另核验 phi 与各 rank 的有符号面地址，接口重复值必须相容。每例仍保留所有壁面零点及歧义反馈。

## Done when

- `python -m unittest tests.test_cfd_re300 -v` 与适用回归 exit 0，包含非法输入、保存策略、来源身份、面通量地址、缺失和冲突测试；先记录失败再实现。
- 保存策略配对已真实执行，并以 `retention-check.json` 精确匹配两次保存时刻和四种场。
- 16 个 `result.json` 原生有效，32 个主涡场识别唯一且稳定；`python studies/run_cfd_re300.py verify --out <目录>` 对源码、协议、输入、原生证据及重新计算结果逐项校验并 exit 0。
- 各域最细三档 GCI≤0.5%，G3 域差/6.751≤0.25%，G3 入口积分偏差≤0.01%，G3 近壁主涡零点差≤0.1% 且小于同域 G2；末两场 X1 相对变化≤1e-5，守恒≤1e-6，流函数路径不闭合≤1e-6。
- 只有所有门槛通过，才按既有保守误差项求和（全矩阵最大参考误差、GCI、域、迭代、参考舍入），上取整到 0.5 个百分点，发布本阶段候选容差。Re=200 的 ±2% 不继承。观测阶及 GCI 不适用必须如实报告。
- 报告提供 16 组对照、主涡和角部可视化、CSV/JSON、反馈、复跑命令与完整交付哈希；旧交付清单前后不变。科学门槛失败也应形成可复核失败报告，不能标为研究通过。

## Stop if

父阶段或任一冻结文件哈希不符；保存策略配对不一致；来源非法或材料缺失；计算发散/超时/资源不足；主涡无法唯一识别；任何 G0–G2 无效（禁止启动 G3）；任何数值门槛未通过（停止后续工况扩展）。保存失败和反馈，不通过放宽阈值或更换参考答案消除失败。
