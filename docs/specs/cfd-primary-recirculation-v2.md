# Re=200 主回流区复核协议 v2

## 目标与边界

仅以新后处理身份复核 `report/2026-09-07-cfd-re200` 已保存的 16 组场（4 网格 × 4 域），包括各组最后两次保存场。禁止覆盖 v1 结果、源文件、公开评分与 10% 容差；不运行求解器、不调用模型。本研究不是盲测，也不是独立求解器复现。

## 论文依据与实现解释

[Erturk 2008, DOI](https://doi.org/10.1016/j.compfluid.2007.09.003)；[作者上传全文](https://www.researchgate.net/publication/223115490_Numerical_solutions_of_2-D_steady_incompressible_flow_over_a_backward-facing_step_Part_I_High_Reynolds_number_solutions)。核对位置：Fig. 1c，Table 5、6，正文对主回流区 X1 的说明（pp. 648–652）。X1 为从台阶到主回流区下游再附着点的距离；角部涡另记 X0–Y0。扩张比 2、Re=200 的 X1/h=4.982。Re 定义使用入口平均速度及入口水力直径 2hi。

以下算法是本 benchmark 对物理对象的离散实现，不能声称是论文原算法。坐标原点位于台阶下角，h=0.01 m；流函数底壁设零，u=∂ψ/∂y，v=−∂ψ/∂x。显示 ψ/(Umean h)，不直接比较论文不同归一化的 ψ 数值。论文上游 20h、下游 300h；本研究上游 5/10h、下游 30/60h，边界及离散方法也不同。

## 在批处理之前固定的选择规则

1. 读取原生矩形单层网格与最后两次 U、phi、wallShearStress。缺失、非有限、重复、非矩形、坐标/单位或身份冲突均拒绝。核验原证据 SHA256。
2. 从下壁向上累积竖直面 +x 通量/厚度，重建节点流函数。以水平面通量核验 Δxψ=−qy，最大路径不闭合量不超过入口每单位厚度通量的 1e−6。该限值沿用原守恒量级，并非参考答案误差限。
3. 对 ψ<0 的节点作四邻接连通分量识别。主涡候选必须在紧邻台阶的第一列连接到台阶上缘分离位置：与 y=h 的距离不超过该位置两档局部竖直网格间距。候选必须唯一；不得用最大面积、最下游零点、固定 x 排除带或参考答案距离选择。
4. 该分量必须有内部负极小值，且在其极小值的 25%、50%、75% 等值线上各有唯一闭合曲线围住极小值。记录所有分量，包括未被选中的角部符号区；不能将角部数值信号直接称作已验证物理小涡。
5. 枚举下壁全部负→正剪切零点。仅当其左侧负剪切壁面单元邻接该主涡分量时才是对应候选，且对应必须唯一。线性插值保留原算法；遇到零值样本/平台则反馈歧义，不猜根。
6. 独立从单元 U 用实际不均匀 y 距离作梯形积分，重建 ψU 并执行同一主涡连通/闭合识别；再用第一层 u/y 和两层不等距二次壁面梯度各自匹配主涡零点。原生 phi 和 U 的识别必须对应同一壁面区间，两个时间点也必须一致。参考 X1、参考涡心坐标不作为选择函数参数。

## 容差与扩展决策

沿用 v1 数值门槛：最细三档 GCI≤0.5%，域差≤0.25%，G3 近壁二次梯度相对原生 X1 差≤0.1% 且小于同域 G2；最末两场 X1 变化≤1e−5；入口积分、残差、守恒、网格/MPI 来源仍须通过原独立验证。不得因新结果临时放宽门槛。GCI 不适用或任何身份歧义均阻止校准。

若全部通过，按原研究的保守误差项求和、向上取整到 0.5 个百分点，发布“研究筛查候选容差”；公开 10% 评分保持不变。新增工况只给出明确阶段决策，本次不自动启动新的原生工况。

## 实施顺序与验收

1. 先写非法输入/多涡/错误归属/零平台测试，记录缺少实现时失败。
2. 新文件实现后处理，保存代码、协议、旧证据清单的哈希作为新身份；先核验旧 delivery manifest，运行旧 `expand_cfd_re200.py verify`，只向新目录写日志。
3. 16 组 × 2 保存时刻重新识别；输出逐例零点、主涡轮廓、独立场证据、GCI、入口/近壁/域/迭代指标。异常以可修复问题反馈。
4. 运行 `python -m unittest tests.test_cfd_primary_recirculation -v`、适用回归测试；新 `verify` 必须只读重算并与保存结果精确一致。
5. 新报告提供可视化与 CSV/JSON，核验页面与链接；旧 delivery manifest 340 项前后哈希一致。

停止条件：任一冻结原证据哈希不符、缺少原生输入、非唯一身份、通量路径不闭合、重算不一致。保留失败产物并报告；不通过修改旧证据或阈值继续扩展。
