# Re=300 v2：近壁分支对应与矩阵续跑

## Objective

以新身份修正二次近壁梯度的分支对应规则；复核已有 Re=300 两组/4 场及 Re=200 16 组/32 场，确认主涡和原生再附着指标不变后，继续四网格四域矩阵。

## Scope

用户本次明确要求的验证边界为：近壁分支匹配的输入/输出、保存场复核 CLI、矩阵恢复 CLI。只新增研究代码与报告，原运行器、旧研究源码/原生数据/失败结果均不改。

1. 主涡仍使用已冻结的 phi、U 积分、台阶连通分量、内部三条闭合流线以及原生壁面零点归属。第一层梯度规则不变。
2. 只改变二次梯度诊断的对应方式。由已确认的原生主零点确定其连续负剪切样本分支；在二次梯度曲线中枚举所有连续负分支，用共享样本索引建立对应。要求原生主分支只重叠一个诊断分支，且该诊断分支也只重叠这一个原生负分支。以对应诊断分支的下游负到正零点作为近壁估计。
3. 允许两个分支的下游零点跨采样区间。保留全部零点、负分支、重叠范围及端点差异。出现分裂、合并、无重叠、未闭合分支、零平台、错位/缺失/非有限采样则拒绝；不按最近零点、参考值或事后距离阈值选取。
4. 两次末场须保持同一原生零点区间、诊断分支端点和对应关系。先复核 36 个保存场，Re=200 原主涡/原生 QoI/原二次估计必须逐项不变；Re=300 原主涡/原生 QoI 不变，并解释旧失败。

## Constraints

- Re=300 的网格、四域、初始化来源、固定 OpenFOAM10 镜像、SIMPLE/离散/残差、purgeWrite 2、双算例并发、G3 四分区 MPI、4 小时单次上限、6/4 GiB 磁盘门槛沿用 v1。核验面通量的有符号分区重构。
- 复核通过后，原两组 Re=300 原生数据复制到新身份作为已保存场复用，显式记录旧路径和 SHA，不声称重新求解。新运行其余 15 组；G0–G2 全有效后才运行 G3。
- 原 Re=300 v1 失败和三份旧交付清单保持不变。新数据在开始前冻结依赖和协议；复核产物单独封存后才放行矩阵。
- 各域最细三档 GCI≤0.5%；G3 域差/6.751≤0.25%；入口偏差≤0.01%；近壁差≤0.1% 且小于同域 G2。末两场原生 X1 相对变化≤1e-5；质量不平衡≤1e-6。容差计算沿用 v1，仅全部门槛通过才发布研究候选值，公开评分 10% 不改，不扩展 Re=400。
- 负分支对应是本基准的数值诊断协议；不把它表述为论文原文定义或三维航空工业验收规则。

## Done when

- `python -m unittest tests.test_cfd_wall_branch -v` exit 0，含非法采样、分裂/合并/无重叠/零平台、角区多个零点、跨区间反例；先记录失败再实现。
- `python studies/replay_cfd_wall_branch.py run --out <新目录>` 生成 18 组、36 场的完整复核，`verify` 重算并 exit 0；保存场和原指标逐项匹配，复核 seal 绑定全部结果。
- 新身份有 16 组有效矩阵结果（1 组复用 + 15 组新原生求解），对照另列；`python studies/run_cfd_re300_v2.py verify --out <新目录>` exit 0，复核来源/输入/原生证据/末两场及矩阵分析。
- 形成四域四网格图、主涡及全部零点可视化、CSV/JSON、反馈、适用边界、测试及交付清单。未通过门槛时形成完整失败报告，不发布候选容差。

## Stop if

冻结来源/材料/哈希有误；36 场复核不全、原主涡/QoI 改变或分支不唯一；保存策略字段不一致；原生超时/发散/资源不足；G0–G2 任一无效；任一研究门槛失败。保留证据，在同一身份下不得修改协议消除失败。
