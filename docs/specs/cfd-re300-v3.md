# Re=300 v3：初始大场读取修复

## Objective

完成 [v2 协议](cfd-re300-v2.md) 已获授权的近壁分支修复、36 场复核与 Re=300 矩阵续跑。v2 在第 12 组读取长域 G3 映射初值时，触发通用字典读取器的 16 MiB 上限；前 11 组原指标均不变，未启动任何新原生求解。v2 的协议、11 组复核记录和停止日志保持冻结。

## Scope

全部主涡、分支对应、网格、原生执行、验证与容差规则沿用 v2。仅将研究网格检查中的 `0/U` 读取替换为已有 `field_dictionary`（正规 ASCII 文件、拒绝链接、128 MiB 上限）；网格点数、边界、入口采样和近台阶坐标检查原样保留。不截断或改写初始速度，不改变通用 16 MiB 读取器。

## Constraints

先冻结 v3 源码与四份父交付清单；重新完整复核 Re=200 的 32 场和两个 Re=300 算例的 4 场，逐项核验原主涡、原生指标及 Re=200 旧近壁指标。复核 seal 通过后才复用两组 Re=300 原生数据，并新求解矩阵其余 15 组。v2 中四网格/四域、先 12 组 G0–G2 后 G3、固定 MPI、资源/超时上限、数值门槛全部保留；不扩展 Re=400，不修改公开评分或参考值。

## Done when

- `python -m unittest tests.test_cfd_re300_large_initial_field tests.test_cfd_wall_branch -v` exit 0；缺失、链接、超过 128 MiB 的初值拒绝；有效大于 16 MiB 的输入保持入口向量，同时旧通用读取器仍拒绝该文件。
- `python studies/replay_cfd_wall_branch_v3.py run --out <目录>` 及 `verify` exit 0，18 组/36 场完整，原指标不变。
- `python studies/run_cfd_re300_v3.py verify --out <目录>` exit 0，16 组矩阵有效（1 组复用 + 15 组新求解），所有 v2 数值门槛通过才形成研究候选容差。
- 交付可视化、CSV/JSON、原生来源、复核和错误反馈，四份旧交付清单逐项不变。

## Stop if

继承 v2 的材料/哈希、主涡/分支、数值、超时和资源停止条件；任一初始场超过 128 MiB 或格式不支持。失败保留原记录，不在原身份下改写结果。
