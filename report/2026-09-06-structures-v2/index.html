接入自己的 agent

在仓库根目录使用本项目 Python 环境。agent.json 指定你的程序，程序按标准 JSON 输入输出协议接收任务并交付建模脚本。

.venv/bin/python -m comacbench run packs/aviation-structures-v2 --agent ./agent.json --out ./structure-run-01

结果目录包含 report.html、逐题 JSON、调用档案，以及完整输入 deck、dat、求解日志的原文和摘要。
