# 民机设计场景贴合度评估（2026-08-26）

> 问题：现在的 COMACBench 还有哪些地方可以更适配民用飞机设计场景？
> 输入：registry 46 条（25 integrated）现状、十维覆盖、深审结论（2026-08-26-deep-audit）、
> 生产环境画像（内网离线、固定模型对 {minimax-m3, glm-5.3}、商业栈 ANSYS/StarCCM+/CATIA/
> Amesim/FENSAP/MATLAB、harness-first 范式）。
> 评估框架：按民机设计院真实工作流（工时占比×独特性）× 本仓实现可行性
> （adapter 现成度/数据源/判分客观性/防泄漏）。

## 0. 一句话结论

**通用工程能力轴（几何/气动/结构/动力/飞控/办公）骨架已立且判分纪律扎实；与「民机设计
独特性」最相关的三块仍是最薄的——适航审定工程、系统安全性设计（FTA/FMEA）、
总体权衡闭环（mdo 1/3）——恰好都是「结构化输出+可客观判分」型任务，与现有
adapter 高度兼容。**

## 2. 五个高价值适配方向（提案）

### P1 适航审定工程轴（建议升维：新增 airworthiness_compliance 维）★★★

**场景**：审定工程师 60-70% 工时在「条款→符合性方法→验证证据」链上。
**现状缺口**：awext 是合成条款卡（civair-kb 联动本会话失败）；无真实条款任务。
**提案三族**（全部结构化输出，复用 json_extract 层）：
1. **ACAM 符合性方法矩阵**：给条款要点+设计特征 → 输出符合性方法选择
   （MC0-MC9 分类）+理由字段；判分 exact/字段级；
2. **条款关联与修订影响**：给条款修订 diff → 受影响系统/文档/下游条款清单
   （结构化抽取+完整性 F1）；
3. **审定文档链追溯**：需求→条款→验证证据映射抽取（多文档输入，输出映射表）。
**数据源路径**：短期自建风格卡扩容（awext DNA）；civair-kb 恢复后按 doc_id 重锚
真实条款（条款文本公开但**语料污染极高**——见 §4 风险）。
**成本**：低（判分层现成）；**场景独特性**：全仓最高（民机 vs 通用 LLM 评测的分水岭）。

### P2 系统安全性设计（FTA/FMEA）★★★

**场景**：民机系统安全性评估（SSA/CCA）是适航审定的强制环节，工时占比高。
**现状**：零覆盖（第 11 维空白）。
**提案两族**：
1. **FMEA 结构化**：功能→失效模式→影响→严酷度/检测方法，输入功能清单或
   半成品表 → 输出规范 FMEA 表（xlsx/design_artifact xlsx_table 模式直接复用）；
2. **故障树与最小割集**：给系统描述 → 建树（结构化 JSON：门/事件）→ 割集计算
   （code_exec：模型写割集求解代码，判分=割集集合精确比对 vs gold 求解器）。
**判分客观性**：强（割集是数学对象；FMEA 字段有 gold）。**成本**：中。

### P3 总体权衡闭环加厚（mdo_design 1/3 → 补厚）★★

**场景**：总体组核心循环=几何→气动→重量→性能→回头改几何。
**提案**：
1. **重量与重心**：分类重量估算（经验公式）、CG 包线计算+配平（code_exec，
   数值判分）；自建参数化；
2. **DOC/航程权衡**：给定任务书与数据 → 计算 DOC 分项/最优巡航（code_exec）；
3. **多工具 agent 链**（harness-first 大显身手处）：cadgen 出几何 → superwing
   风格系数查询 → 重量估算 → aviary 航程，四工具串联小闭环；判分=末端性能数值+
   中间制品结构。固定模型对+arm_router 正好测编排。
**成本**：中（工具都在，串联 runner 需小扩展）。

### P4 气动数据工程化（cfd 维实用层）★★

**场景**：气动组大量工时在「散点数据→可查询气动数据库」。
**提案**：气动 deck 构建（给多工况 CFD/风洞散点 → 实现插值 API，判分=插值精度
vs gold 网格，容差分级内插/外推）；风洞-CFD 相关性修正（对齐+修正因子）。
**复用**：field_prediction 的划分纪律（几何分组内插/外推分报已有）。
**注**：deep-audit 已列 scoring §6 三组误差缺口——本方向可一并补「工况外推」组。

### P5 载荷谱与结构检查（structures 加厚）★

载荷包线（机动+突风组合）、工况筛选表（engtable exceed 族风格）、元件许用应力
对比检查（calculix 后续：给 FEA 结果+许用值 → 检查结论表）。

## 3. 已验证的死路（不再追）

- GUI/computer-use（Fusion/AutoCAD 双实验证死 + Seldon 38 题种子私有）；
- 全量体数据（hilift_full 66.9TB 已排除）；
- Web 依赖类（内网离线）；
- 自由写作类（LLM judge 违纪律）。

## 4. 两个前置风险（做 P1 前必须正视）

1. **条款语料污染 × 隐藏层未接线（深审 M10）**：CCAR/FAR 条款文本公开且大概率
   在训练语料里——真实条款任务**必须**先接线 hidden-dynamic（动态改写/轮换），
   否则测的是背诵。M10 的裁决（接线 vs 改标志）从「技术债」升格为 P1 的**前置依赖**；
2. **KB 通道**：civair-kb 本会话三端点不返回内容——P1 短期走自建卡，KB 恢复
   是升级触发器而非阻塞项。
