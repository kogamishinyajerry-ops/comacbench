# TMR flat plate 网格收敛审计（阶段一～四）：此前 GCI 结论作废

日期：2026-09-21（晚场） ｜ 分支：`codex/trusted-resume-and-formula`（接 `cb6a95fa`）
前置证据：`report/2026-09-21-tmr-flatplate-converged/`（该报告的核心结论在本轮被推翻）

## 0. 一句话

**`report/2026-09-21-tmr-flatplate-converged` 里"粗网格系统性 -17%"的结论是错的。**
真因是 STAR-CCM+ 的迭代上限设置**静默失效**（所有 run 只跑了默认 1000 步），细网格的
k 方程远未收敛。把 137×97 档跑到 6000 步，完全湍流区偏差从 **-17.4% 收敛到 -8.4%**，
尾缘从 -16.5% 收到 **-1.9%**——偏差是「没跑够」，不是「网格粗」。

阶段二进一步：273×193 的「τ 崩塌」同样被证伪——种子化初始湍流条件后 Cf 从
5.5e-4 升到 1.69e-3（层流量级 → 湍流量级）。**但细网格的 Cf 仍在向参考攀升，
三档 GCI 依然不能收口**（详见 §9），需要先解决「迭代到平稳」或「前缘奇异点伪 k 生成」
其中之一。

阶段三（§10）做了三件事：① 把 `long273` 跑完，否掉「靠蛮力迭代能救回默认 IC」；
② 发现收敛门**两个层级别混淆**并修掉（`ok` vs `strict_ok`）；③ 用站位插值做**形状诊断**，
把「GCI 为什么收不了口」从一个模糊的「没收敛」收窄成一个具体的**形状不匹配**：
参考 Cf 在前缘有峰、随后按 x^-0.14 衰减，而模型的 Cf(x) 几乎是平的（斜率 -0.02~-0.05）。

阶段四（§11–13）又把结论翻了一次，而且翻得更狠：

1. **口径错了。** 从二维切片场反推运动粘度，得 ν = 1.56659e-5（52224 样本，
   离散度 0.01 %），即 STAR-CCM+ 默认空气的 μ/ρ。于是 U=50 对应
   **Re_unit = 3.19×10⁶，不是 TMR 要求的 5×10⁶** —— 此前所有比较都在低 36 % 的
   雷诺数下做的（§11）。
2. **"迭代不够"被彻底否掉。** qoi273 跑到 12000 步，Cf 在 6000–8000 步出现肩部后
   转入**缓慢下滑**（增量 −0.12 → −0.20 %/1000 步仍在放大），斜率稳定在 **−0.0295**
   而参考是 **−0.1408**。**它不会走到参考上去**（§10.9）。
3. **两个轴同时出局。** 137 与 273 同形状；入口湍流强度改 26 倍、形状**纹丝不动**
   （§12）。⇒ 形状误差既不是网格分辨率，也不是入口湍流量级。
4. **真正的杠杆点找到了**：场侧 sanity 显示外区很干净（k 0.359→0.030，μt/μ 10→8.2），
   但**贴壁前段有一个 k 高达 114.6 m²/s²（Ti=17 %）、μt/μ 高达 617 的污染层**，
   跨越 26–60 倍。**决定 Cf 的正是这个高 μt 区**——它把边界层的 x 依赖压掉，
   于是 Cf(x) 变成常数（§13）。

⇒ **当前唯一在跑的关键实验是 `qoi78`（Re 修正版）**，用来判定形状误差里有多少是口径、
有多少是近壁污染（§14）。

## 1. 触发线索：a4 与 a4t 逐字节相同

排查时先发现两件「不该发生的事」：

| 证据 | 结果 | 含义 |
| --- | --- | --- |
| `md5sum tau_a4.daten tau_a4t.daten` | **完全相同** | a4t 那次 run 什么都没改 |

根因：a4t 用了错误的中文键（`湍流规范`），两段 `try` 都抛
`Named object ... does not exist in manager` 被吞掉，宏照常 `EXIT=0`。
**宏静默失败是本轮所有误判的共同形态。**

## 2. 三条 R8 macro 静默失效陷阱（反射探查实证）

### 2.1 迭代上限：只有 typed setter 生效

```java
msc.set("MaximumSteps", 1500);        // ❌ ClientServerObject.set(String,int) = 静默 no-op
((StepStoppingCriterion) msc).setMaximumNumberSteps(6000);   // ✅
```

实测回读：`LR-BEFORE-MAXSTEPS 1000` → `LR-AFTER-MAXSTEPS 6000`。
此前 a3/a4/a5/a4t2 **全部只有 1000 步**（默认值），而宏里"设了 1500"是无效果的。
`SimulationIterator` 也没有 `MaximumIterations` 键。

### 2.2 方法选择器与数值 profile 是两个对象

- 湍流方法选择器的键名是 **`湍流指定`**（`star.kwturb.KwTurbSpecOption`），选项枚举
  `star.kwturb.KwTurbSpecOption$Type` = `K_OMEGA` / `INTENSITY_LENGTH_SCALE` /
  `INTENSITY_VISCOSITY_RATIO`。**不存在 `湍流规范` 这个键。**
- 入口与初始条件的默认选择器**都已经是 `INTENSITY_VISCOSITY_RATIO`**，默认
  Ti = 1 %、TVR = 10。
  ⇒ **此前"细网格崩塌是因为入口湍流规格缺失"的诊断是错的**（a4t2 反而把入口 k 降了 100×）。

### 2.3 场函数按 function name 查，不是显示名

`getFunction("Turbulent Kinetic Energy")` 静默返回 `null` → 报告报
`Field function is not set`。必须用 `TurbulentKineticEnergy` / `SpecificDissipationRate` /
`TurbulentViscosityRatio` / `WallYplus` 等英文无空格的 function name。
（`Centroid`/`Velocity`/`WallShearStress` 恰好同名，所以以前没暴露这个问题。）

## 3. 「Tke 残差 82 = 发散」也是误判

a4t2 的 Tke@1000 = 82.2，看着像发散。逐迭代对照后发现它与 a4（默认 Ti=1 %）
**轨迹形状完全相同、比例恰好 ≈100×**：

| iter | a4 / long273（Ti=1 %） | a4t2（Ti=0.1 %） | 比值 |
| --- | --- | --- | --- |
| 51 | 4.8869e-01 | 5.1447e+01 | 105 |
| 301 | 6.4896e-01 | 6.7283e+01 | 104 |
| 501 | 5.7665e-01 | 5.7819e+01 | 100 |
| 755 | 6.6451e-01 | 6.7115e+01 | 101 |

`k_inlet ∝ Ti²`，Ti 差 10× ⇒ k 场差 100× ⇒ **残差按 k 量级归一化，整体缩放 100×**。

> **纪律**：湍流残差的绝对量级不可跨算例比较。同一 273 网格，Ti=1 % 时 Tke@1000
> 其实是 **0.826**，不是 82.2。

## 5. 收敛门判据（已实现为仓库件）

`runners/tmr_cf.py::convergence_report` = continuity/momentum 阈值 + 最近窗内湍流残差
不得系统性回升（默认窗 300 步、允许回升 5 %）。对历史日志回测：

| 日志 | 判定 | 最近窗 Tke 漂移 |
| --- | --- | --- |
| `allin3`（137 @1000） | PASS | −36.05 % |
| `long137`（137 @6000） | **PASS** | **−0.02 %** |
| `allin_a4`（273 @1000） | **FAIL** | **+30.61 %** |
| `allin_a5`（545 @1000） | PASS | −9.27 % |
| `allin_a4t2`（273/Ti0.1% @1000） | FAIL | +28.94 % |

判据成功拦住了产出「伪层流 Cf」的那次 273 run。

### 5.1 但残差门通过 ≠ 解正确

545×385 档残差**平滑下降**（Tke 0.54 → 0.49，单调）却在 1000 步时壁面 τ 崩塌
（Cf ~1e-5，见第 6 节）。**必须叠加场侧 sanity**：壁面 k > 0、μt/μ > 1、Cf 量级对
层流量级（`0.664/√Re_x`）留出合理裕度。

### 5.2 前缘奇异点会把 k 残差"托底"

上游对称面近前缘处的伪湍动能尖峰在 50 m/s 来流下达到 **k ≈ 26–93 m²/s²**：

| 位置 | 137×97 @1000 | 273×193 @1000 | 137×97 @6000 |
| --- | --- | --- | --- |
| 上游对称面 k（x<0, z=0） | 81.3 | 26.3 | 92.7 |
| 入口 k | 0.375 | 0.375 | 0.375 |
| 出口 k | 0.507 | 2.346 | 0.389 |
| 出口 μt/μ | 30.6 | 117.5 | 28.1 |
| 壁面 y+ | 0.107 | 0.058 | 0.112 |

这是个持续的残差源 ⇒ 本 case 的 k 残差可能长期停在 0.1–1 量级而不趋零。
**⇒ `nasa_tmr.verification` 的收敛定义必须落在 QoI（Cf）平稳 + 场侧 sanity，而不是
k 残差阈值。** 否则该任务永远过不了自己设的 gate。

（参考统一取 CFL3D zone）

| 档 | 全板插值偏差 | 完全湍流区偏差 | 完全湍流区 Cf 均值 | 壁面 Cf 量级 |
| --- | --- | --- | --- | --- |
| 137×97 @1000 | −25.4 % | −17.4 % | 0.002206 | 湍流级 |
| 137×97 @6000 | −21.2 % | **−8.4 %** | 0.002447 | 湍流级 |
| 273×193 @1000 | −71.8 % | −79.4 % | 0.000550 | 0.00044 |
| 545×385 @1000 | −99.7 % | −99.8 % | 0.000006 | ~1e-5（τ 崩塌） |

层流参照：`Cf_lam = 0.664/√Re_x`，x=1 处 Re_x = 3.19e6 → **3.72e-4**。
273 档给出 **4.43e-4 ≈ 1.19× 层流值** ⇒ 该解基本无涡粘，是**初始化/收敛**问题而非网格效应。

### 6.1 已定位的一个具体缺陷：湍流初始条件参考速度

IC 的 k 由 `k = 1.5·(Ti·V_ref)²` 得到，`V_ref` 取自初始条件对象 **`湍流速度比例`**，
**默认只有 1.0 m/s**（与来流 50 m/s 无关）：

- IC k = 1.5·(0.01·1.0)² = **1.5e-4**
- 入口 k = 1.5·(0.01·50)² = **0.375** —— 相差 **2500×**

细网格单元小、k 只能靠对流/扩散从入口输运进来，所以粗网格靠数值扩散"蒙对"、
细网格来不及发育。**修正**：把 IC 的 `湍流速度比例` 设为 50 m/s，实测
`INIT-K-OUT` 从 1.5e-4 变为 **0.375**（与入口一致）、`INIT-OM-OUT` = 2393.7。

### 6.2 数据完整性修正：参考文件其实是双 zone

`cf_plate_sstv.dat` 含 **两个 zone**：第 2 行 `zone, t="CFL3D"`、第 546 行
`zone, t="FUN3D"`（990 行数据里 447 个 x 站点各出现两次，两侧 cf 不同）。

此前所有比对都把两个 zone **按行拼成了一条混合曲线**，插值指标实际是拿
「CFL3D + FUN3D 混合」当参考。影响量级不大（两求解器本身接近，修正量 ≈ 0.2–0.3 pp：
`long137` 完全湍流区 −8.12 % → **−8.40 %**），但**结论口径必须统一**。
`runners/tmr_cf.py::read_reference` 已改为 **fail-closed**：多 zone 且未显式指定
`zone=` 时直接抛错，另提供 `reference_zones()` 列出可选 zone。

> 这条同时意味着 `report/2026-09-21-tmr-flatplate-converged/` 里所有 Cf 偏差数字的
> 参考口径也是"混合 zone"，引用时需重算。

## 9. 阶段二：细网格 τ 崩塌定位为初始化伪像，但 GCI 仍不能收口

`seed273`（273×193，IC `湍流速度比例` = 50 m/s，3000 步）跑完。**这是本轮最关键的判定**：

| 档 | 完全湍流区 Cf 均值 | 对 CFL3D 偏差 | 性质 |
| --- | --- | --- | --- |
| 137×97 @1000 | 0.002206 | −17.4 % | 湍流级 |
| 137×97 @6000 | 0.002447 | **−8.4 %** | 湍流级 |
| 273×193 @1000（默认 IC） | 0.000550 | −79.4 % | **准层流** |
| **273×193 @3000（种子化 IC）** | **0.001685** | **−36.9 %** | **湍流级** |
| 545×385 @1000 | 0.000006 | −99.8 % | τ 崩塌 |

（层流参照 `Cf_lam` @x=1 = 3.72e-4；CFL3D 的 x ≥ 0.5 均值为 0.002671）

### 9.1 结论一：「τ 崩塌」是初始化/收敛伪像（已定案）

种子化 IC 后 273 档的 Cf 从 **5.5e-4 → 1.69e-3（3× 提升）**，离开层流量级、进入湍流级，
收敛门在 3000 步 PASS（最近窗 Tke 漂移 −5.89 %）。配合阶段一 137 档从 −17.4 % → −8.4 % 的
收敛，**「细网格物理上算不出来」这一判断被排除**；此前 `2026-09-21-tmr-flatplate` 与
`-converged` 两份报告里"细网格 τ 崩塌 / 缺入口湍流规格"的诊断均为误判。

### 9.2 结论二：却仍不能做 GCI —— 细网格还在演化且更偏离

273@3000 的 −36.9 % **比粗网格 137@6000 的 −8.4 % 更差**，与网格收敛方向相反。
可见的单调趋势（5.5e-4 @1000 → 1.69e-3 @3000，向 0.00267 攀升）说明
**细网格仍处于湍流发展瞬态中**，且 k 场的横向重分布很慢：

| 位置量 | 137@1000 | 273@1000（默认 IC） | 273@3000（种子化） |
| --- | --- | --- | --- |
| 出口 k | 0.507 | **2.346** | 1.002 |
| 出口 μt/μ | 30.6 | **117.5** | 55.0 |
| 上游对称面 k（前缘尖峰） | 81.3 | 26.3 | 73.2 |
| 壁面 y+ | 0.107 | 0.058 | 0.095 |

注意 **「出口 k 越大 → 壁面 Cf 越低」**：默认 IC 那次出口 k 是种子化的 2.3 倍，Cf 却只有 1/3。
这说明湍动能主要被**前缘奇异点的伪 k 尖峰**注到外层，没有有效驱动内层边界层。

⇒ **三档 GCI / Richardson 外推不具备可交付条件**，必须先解决下面任一项：

1. **把迭代跑到真正平稳**：细网格需要远超 3000 步（粗网格用了 6000 才到 −8.4 %），
   代价高昂，且需以 Cf 平稳（而非 k 残差）为判据；
2. **压掉前缘奇异点的伪 k 生产**：上生产限制器 / Kato-Launder，让 k 尖峰不再随网格变化
   ——这是 TMR 类 case 的标准做法，也是最可能让三档真正收敛的路径。

阶段一已定的纪律在阶段二仍然成立：**判据必须落在 QoI（Cf）平稳 + 场侧 sanity**。
`long273`（默认 IC，6000 步）仍在跑，作为「靠蛮力迭代能否救回默认设置」的对照。

## 10. 阶段三：`long273` 回报 + 收敛门两级化 + 形状诊断

### 10.1 `long273`（273×193，默认 IC，6000 步）：蛮力迭代只能救回一半

`long273` 与 `long137` 是**干净的受控对**（同 macro 族、同默认 IC、同 6000 步，只差网格）：

| 档 | K_IN | K_OUT | 收敛门 | `strict_ok` | Cf(x≥0.5) 偏差 | 壁面 y+ |
| --- | --- | --- | --- | --- | --- | --- |
| `long137`（137×97） | 0.375 | 0.389 | PASS（漂移 −0.02 %） | **True** | **−8.40 %** | 0.112 |
| `long273`（273×193） | 0.375 | 0.411 | PASS（漂移 **−10.46 %**） | **False** | **−5.88 %** | 0.114 |
| `seed273`（273×193，种子化 IC） | 0.375 | **1.002** | PASS（漂移 −5.89 %） | True | **−36.9 %** | 0.095 |

> 偏差口径统一为 `fully_turbulent_mean_cf`：模型侧与 CFL3D zone 各自在 x∈[0.5, 2.0]
> 内取点均值，再算相对差（参考均值 0.002671）。这是 GCI 判分用的同一把尺子，
> 不要再和 §4/§9 里按 bin 均值算的旧数字混用（两者差 ~0.02 pp，但口径要写明）。

**两点结论：**

1. **默认 IC 靠迭代可以走一段路，但 6000 步不够。** `long273` 从 273@1000 的 −79.4 %
   收回到 −5.88 %，且**比 137@6000 的 −8.40 % 更好**——网格加密方向终于对了。但它的
   Tke 残差仍在以 **−10.46 %/300 步**下降（对比 137 的 −0.02 %），说明**还差得远**。
2. **「改 IC」不是解药。** `seed273` 的形状对了（见 10.3），水平却掉了 36 %。IC 只改变
   瞬态起点，不改变最终要去的地方。

### 10.2 修掉一个真实缺陷：收敛门混淆了两个级别

原 `convergence_report` 对湍流列只做**单侧**判定（`peak > first·(1+5%)`，即只抓
「回升」），于是 `long273` 拿到的结论是 `ok=True, turbulence_stationary=True`——
**对一条仍在下滑 10.46 %/300 步的曲线做出了「平稳」的声明**，属过度声明。

设计本意没错（单调下降是健康行为，`test_decaying_residuals_pass` 就是把这条契约钉住的），
错在**只暴露一个布尔**。现拆成两个：

| 判定 | 含义 | 进哪个字段 |
| --- | --- | --- |
| 回升（rebound） | 发散 / 极限环，解是**坏的** | `ok`（保持原语义） |
| 持续下滑（still-drift） | 还没跑够，解是**好的但没到位** | `drift_ok`（新），`|drift| > decay_tol` 触发 |

新增 `ConvergenceVerdict.strict_ok = ok and drift_ok`，并把 `richardson_gci` 的前置条件
从 `ok` **改写成 `strict_ok`**。实测判别力：

```
long137_out.log: convergence PASS @ iter 6000
    ok=True strict_ok=True (drift_ok=True, decay_tol=0.1)
long273_out.log: convergence PASS @ iter 6000 (still-drift: strict gate would reject) | tke still drifting in last 300 iters (-10.46% net, |drift| > 10%)
    ok=True strict_ok=False (drift_ok=False, decay_tol=0.1)
```

同时新增 **QoI 平稳性判据** `qoi_stationary()`（见 10.5）——因为 §5.2 已证明湍流残差
量级跨算例不可比，「残差数值小」既非充分也非必要条件。

## 11. 阶段四（一）：口径错误——Re 不是 5×10⁶，而是 3.19×10⁶

### 11.1 反推运动粘度：三个独立组合全部指向同一值

`field_side273.daten`（Y=0 全二维切片，52224 个面，来自 `fp3d_Q273.sim`）同时带了
ω、k、μt/μ 三个场。三者与 ν 有硬约束关系（SST 的 μt = ρk/ω）：

```
nu = k / (omega * TVR)
```

对全部 52224 个面做该反推：

| 统计量 | 值 |
| --- | --- |
| median | **1.56659e-05** |
| mean | 1.56886e-05 |
| min / max | 1.56646e-05 / 2.72e-05 |
| STAR-CCM+ 默认空气 μ/ρ = 1.85508e-05/1.18415 | **1.56653e-05** |

中位数与默认空气值一致到 **0.004 %**，且 99 % 的样本落在 ±0.01 % 内。

⇒ **本轮及此前所有 run 的 ν = 1.5666×10⁻⁵ m²/s，不是 1×10⁻⁵。**

### 11.2 后果：Re_unit 差 36 %

`U = 50 m/s`、`ν = 1.5666e-5` ⇒ **Re_unit = U/ν = 3.1917×10⁶**，
而 TMR 参考要求 `Re_x(x) = 5×10⁶·x`。

判据：参考本身自洽——`cf_plate_sstv.dat` 在 x=1 处 Cf = 0.002679，
反解标准湍流平板相关式 `Cf = 0.0592 Re_x^-0.2` 得 Re_x = 5.27×10⁶，
即参考的 Re_unit 确为 5×10⁶（±5 %）。**是我们的 Re 低了 36 %。**

修正方案（唯一自洽解）：`U = 5×10⁶·ν = 78.33 m/s`。

副作用校验：取 TMR 的入口湍流口径后
`k = 1.125U²/Re_L = 1.3806e-3`、`ω = 125U/L = 9791.83`，
其等效 (Ti, TVR) 恰为 `Ti = sqrt(2k/3)/U = 3.873e-4`、`TVR = 0.009` —— 与 `tmrfix273.java`
里写的常数**完全吻合**。这不是巧合：TMR 的 k、ω 公式与 (Ti, TVR) 口径在 ν=1.5666e-5 下互为等价。

### 11.3 这一条**不能**用来解释形状错误（重要）

若按 Re 修正重算，正确解在"我们错误的 Re"下应比参考**偏高**
（(5/3.19)^0.2 = +9.4 %）。而实测 L273 是**偏低 −5 %**，
所以 Re 修正只会让水平偏差**变大**（约 −14 %），不会变小。

⇒ Re 错误是**必须修的口径缺陷**（否则任何量化比较都无意义），
但它**不是** §12/§13 那个平直的 Cf 形状的原因。两者要分开处理。

## 13. 阶段四（三）：场侧 sanity——近壁区被 μt 污染（真正的杠杆点）

用 §11 那份二维切片做剖面。**外区是干净的**：

| 位置 | u | k | μt/μ |
| --- | --- | --- | --- |
| 入口上游远场 z=0.97 | 50.000 | 0.359 | 9.97 |
| 出口远场 z=0.97 | 50.0 | 0.0299 | 8.17 |

k 从 0.359 衰减到 0.0299、μt/μ 从 10 落到 8.2 —— 正常的自由来流衰减。

**但贴 z=0 面的前段不是**（z 即壁法向，板在 z=0；x<0 是上游对称面区）：

| 站位 | z | u | k | μt/μ |
| --- | --- | --- | --- | --- |
| x=−0.323（入口旁首列） | 5.0e-7 | 40.4 | 33.7 | 39.1 |
| x=−0.284 | 5.0e-7 | 15.9 | 111.8 | 155.6 |
| x=−0.234 | 5.0e-7 | 11.4 | 107.0 | 232.4 |
| x=−0.181 | 5.0e-7 | 9.85 | 102.3 | 279.0 |
| **x=0.001（板前缘正上方）** | **2.78e-3** | **20.7** | **89.7** | **617.1** |

全场极值：**k_max = 114.6 m²/s²**（x=−0.2665）、**ω_max = 1.253e9 s⁻¹**（x=0.001, 贴壁格）、
**μt/μ_max = 896.6**。

三点读数：
1. k = 114.6 m²/s² 对应 **Ti = 17 %**（U=50 时），而入口给的是 0.375（Ti=1 %）——
   近壁/前段的湍动能比来流高 **两个量级**。
2. 外区 μt/μ ≈ 10，近壁区 40 → 280 → 617，跨越 **26–60 倍**。**决定 Cf 的正是这个高 μt 区。**
3. 前缘正上方那格 μt/μ = 617 —— 一个近乎"饱和"的涡粘性，会把壁面速度梯度抹平，
   这正是"前缘 Cf 低 40 %"的直接机制。

**这解释了 §10.3 的形状诊断**：Cf(x) 近乎常数（斜率 −0.03 vs 参考 −0.14），
不是边界层"没发展"，而是**壁面剪切被一个空间上近似均匀的高 μt 包层所设定**，
边界层自身的 x 依赖被压掉了。

### 13.1 诚实边界：这条还没定案

- 该切片是 **qoi273（U=50、默认 IC、12000 步）** 的状态。同期 Cf 仍在缓慢下滑
  （§10.9），所以**不能排除**这是尚未衰减完的慢瞬态，而非稳态特征。
- 上游对称面上出现 du/dz = 0（真对称面行为）而**其上方**是低速高 k 层，
  说明这不是"对称面被当成壁面"，而是**板上游被一个分离/回流型结构占据**。
- 因此本阶段**只把它定为"最强嫌疑 + 唯一剩下的杠杆"**，不定为结论。
